Genovês

Do primeiro aprendizado ao pensamento crítico.

O Genovês é um projeto de aplicativo educacional que busca unir métodos clássicos de aprendizagem às possibilidades da tecnologia atual.

Objetivo

Criar um ambiente digital de aprendizagem que incentive o desenvolvimento do conhecimento, da autonomia e do pensamento crítico.

Proposta

O aplicativo está sendo desenvolvido para oferecer:

- Feed educacional com conteúdos, artigos e publicações.
- Missões e atividades de aprendizagem.
- Quizzes e enquetes.
- Ambientes específicos para alunos e professores.
- Experiências de aprendizagem interativas.

Tecnologias

- Flutter
- Dart
- Git e GitHub

Status do projeto

Em desenvolvimento.

Esta versão é um protótipo destinado à apresentação e aos testes iniciais. Algumas funcionalidades ainda estão em construção.
